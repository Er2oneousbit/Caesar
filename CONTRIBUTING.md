# Contributing

**Bug reports are welcome.** If something in the game does not work the way it should, [open an issue](https://github.com/Er2oneousbit/Caesar/issues/new/choose) with the bug report form. What helps most:

* what you did, what you expected, and what happened;
* your browser and operating system;
* a save file (*Save game → Copy save data*, pasted into a `.json` file and attached) or, if you got the "Something broke in the city" screen, the text from its *Copy report* button;
* a screenshot, if it is something you can see.

Colonia is released under the [MIT License](LICENSE), so you are free to fork it and make your own version.
