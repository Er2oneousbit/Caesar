# Code of Conduct

Colonia is a hobby project about building cities, so let's build a friendly one.

## The short version

- **Be kind and assume good intent.** People of every background and skill level are welcome here, including first-time contributors.
- **Critique code and ideas, not people.** "This loop allocates every tick" is useful; "you clearly don't know JavaScript" is not.
- **No harassment.** That includes insults, slurs, personal attacks, sexual content, unwelcome attention, doxxing, or sustained disruption of discussions.
- **Keep it on topic.** Issues and pull requests are for the game.
- **Respect "no".** If someone asks you to stop, stop.

## Where this applies

Everywhere the project lives: issues, pull requests, discussions, commit messages and any other project space.

## Reporting

If something here makes you uncomfortable, contact the maintainer privately through GitHub ([@Er2oneousbit](https://github.com/Er2oneousbit)) or use GitHub's "Report content" feature. Reports are kept confidential.

## Enforcement

The maintainer may edit or remove comments, close issues, or block people who don't follow this code, starting with a friendly warning where that makes sense.
